# A to D: local workspace and detailed LiDAR handoff

The Lane A human approved Lane D's no-sign-in local demo. iOS loads `/scans/{scanID}` directly on the configured local workspace origin, with same-origin navigation and main-frame `nativeCapture` / `scanShop` checks. Hosted no-sign-in workspaces remain disabled; no provider key enters the WebView.

The real `ravida` upload is ready: `af42f6cd-d228-4dd8-8790-aff0890fee5b`. It includes a 77,304,881-byte H.264 walkthrough and 284 frame images. The metadata mapping is a binary plist. iOS uploads mapping, poses and coverage first, then USDZ and room JSON, and immediately finalizes; video/images continue afterward. The processing input therefore includes coverage and mapping without waiting for video. Late media should remain post-processing extras until D defines a reprocessing protocol.

The human authorized the full reconstruction path. `lidar_mesh` now flows through the shared contract, validated artifact upload and `GET /api/scans/{id}/lidar-mesh`. Native and web review render actual triangles first; RoomPlan boxes supply conservative object labels, not replacement geometry. Detailed mesh uploads before finalization, while video/images remain the optional tail. Legacy scans without mesh retain their existing upload path.

Format: `{ "parts": [{ "id": "UUID", "transform": [16 column-major floats], "vertices": [x,y,z,...], "triangles": [three UInt32 indices per triangle] }], "floorY": -1.67, "peopleFilteringEnabled": true }`. Metadata is optional for older captures. Vertices are anchor-local meters; transforms place them in RoomPlan's Y-up AR world. Web applies the same first-floor height shift as scene ingest, then retains Y-up. The viewer requires floor alignment metadata and shows a retry message if detailed geometry fails to load.

Ravida's 93 parts / 460,497 vertices / 819,498 triangles render in the production web workspace. Its filtering metadata remains unknown: only new captures enable ARKit person segmentation plus scene reconstruction. Video/images are not privacy-redacted or texture-fused. Recognized RoomPlan objects remain 3 tables, 11 chairs and 1 storage unit; unmatched measured shapes stay visible without invented labels.

Build and run the demo web with `SP_API_ORIGIN=http://10.20.9.207:8787` in both commands; Next.js freezes rewrites at build time. Workspace is port 3001; unrelated services occupy port 3000 and loopback 8787. Phone uses the existing `.local` API origin to retain upload receipts and numeric LAN workspace URL. Ravida's mesh was upgraded with floor metadata on phone/server with identical bytes; migration preserves already-aligned files.
